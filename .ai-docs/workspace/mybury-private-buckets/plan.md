# mybury-private-buckets 마이버리 이관 버킷 비공개

## 의도

마이버리에서 이관된 버킷이 타인에게 보인다는 사용자 신고를 해결한다. 이관 시 비공개로 저장되고, 권한 없는 사용자의 조회 응답에 포함되지 않으면 완료한다.

## 확인한 사실

- `MyburyMigrationService.migrateBuckets`는 모든 이관 버킷에 `ExposureStatus.PRIVATE`를 명시한다. 원본 공개 값이나 친구 목록을 복사하지 않는다.
- `BucketAccessPolicy`는 소유자와 참여자가 아닌 사용자의 `PRIVATE` 상세 조회를 막는다. 이관 버킷은 친구 목록이 없으므로 생성 직후 함께하기 버킷이 아니다.
- `BucketRepositoryImpl`의 검색, 공개 목록, 인기 목록은 공개 조건을 적용한다. 피드는 `PUBLIC`과 맞팔로우 대상의 `FOLLOWER`만 포함한다.
- `OtherMyResponse`는 타인 프로필에서 공개 조건 없이 `user.getBucketlist()`를 전부 반환한다. 이관 시 비공개로 저장해도 이 경로에서는 노출될 수 있다.
- 실제 신고 데이터의 저장 값과 앱이 연결한 배포본은 확인하지 않았다. 이관 코드에서 공개 저장이 발생했다고 단정하지 않는다.

## 합의

### 이관 버킷 비공개 유지

- 바꾸는 것: 이관 버킷이 권한 없는 사용자에게 노출되는 조회 경로를 막는다.
- 모양: 이관 시 `PRIVATE` 저장을 유지하며, 타인 조회 목록과 개수에 비공개 이관 버킷을 포함하지 않는다.
- 이유: 이관 저장 코드에는 이미 비공개 지정이 있어, 확인된 조회 검사 누락을 수정하는 것이 필요한 변경이다.
- 적용 범위: `bucket-visibility`의 타인 프로필 조회 수정과 마이버리 이관·조회 회귀 검증. 출처는 사용자 요청 4번이다.

## 연결

- 타인 프로필 조회 수정은 `bucket-visibility` 계획을 따른다. 중복된 별도 노출 정책을 만들지 않는다.
- 네 이슈를 모두 확인한 뒤 한 번에 수정한다.

## 검증

- 이관된 버킷의 공개 값이 `PRIVATE`이고 함께하기가 아닌지 확인한다.
- 소유자는 조회할 수 있고, 타인 프로필 목록과 개수에는 포함되지 않는지 확인한다.
- 함께하기의 `PUBLIC` 고정 변경이 친구 목록 없는 이관 버킷을 공개로 변경하지 않는지 확인한다.
- `MyburyMigrationPrivacyTest`가 통과했다. 저장소 모의 객체를 사용하여 완료·진행 중 이관 버킷 모두 `PRIVATE`로 저장되고, 타인 프로필에는 목록·개수가 0이며 소유자에게는 두 건이 표시됨을 확인했다. 실행 명령은 `bucket-visibility/plan.md`의 검증 절을 따른다.
